# CREATE A STRONG PASSWORD AND EVALUATE ITS STRENGTH

## Objective:
To understand the importance of strong passwords and evaluate their strength using an online password strength checker.

## Tool Used:
- Password Meter (Online Password Strength Checker)

## Password Strength Evaluation:

| Password | Strength |
|-----------|-----------|
| P@d10 | Very Weak |
| P@dm@!!10 | Weak |
| $!/>10@md@p | Fair |
| AMDAP$!/>10@ | Strong |
| &1R#22P@dMW\*10-a | Very Strong |

## Analysis:

### 1. P@d10 - Very Weak
- Short password length.
- Easy to guess.
- Provides low security.

### 2. P@dm@!!10 - Weak
- Contains symbols and numbers.
- Still relatively short.
- Better than a simple password but not highly secure.

### 3. $!/>10@md@p - Fair
- Uses special characters and letters.
- Improved complexity.
- Offers moderate security.

### 4. AMDAP$!/>10@ - Strong
- Good combination of uppercase letters, numbers, and symbols.
- Difficult to guess.
- Provides strong protection against common attacks.

### 5. &1R#22P@dMW*10-a - Very Strong
- Long password length.
- Includes uppercase letters, lowercase letters, numbers, and special characters.
- Highly resistant to brute-force and dictionary attacks.

## Common Password Attacks:

### Brute Force Attack
-An attacker tries every possible password combination until the correct password is found.

### Dictionary Attack
-An attacker uses a list of common words and passwords to guess login credentials.

## Conclusion:

Password strength depends on length, complexity, and randomness. 
Strong passwords significantly improve security and help protect user accounts from unauthorized access. 
Based on the evaluation, passwords with longer lengths and a combination of character types provide the highest level of security.

Successfully understood password security concepts and learned how password complexity affects overall cybersecurity.
